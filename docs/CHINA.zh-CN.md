# Ergon 在中国

> 葡萄牙语版本：[CHINA.md](CHINA.md)。

在中国，Ergon 是**安装在你电脑上的社区版（Community）**，使用**中国的 AI**。那里不提供 Ergon 云服务和计费：
一切都在你的电脑上运行，密钥和数据都留在本机。

## 1. 通过镜像安装

在中国，GitHub、`ghcr.io`、PyPI 和 Docker Hub 经常无法访问或非常慢。Ergon 的镜像也会发布到中国境内的镜像仓库，
其**摘要（digest）与 `ghcr.io` 上的完全相同**：内容一致，并经过校验。

1. 通过在中国能打开的地址（或从已下载的同事那里）获取 Ergon 本地安装包（`ergon-local-<版本>.zip`），解压到一个文件夹。
2. 在该文件夹中创建（或打开）`.env` 文件，加入镜像这一行：

   ```
   ERGON_REGISTRY=registry.cn-hangzhou.aliyuncs.com/<Ergon 的命名空间>
   ```

   具体地址以 Ergon 版本说明中公布的为准。有了这一行，启动脚本会从镜像下载 Ergon 的两个镜像，并在本机使用原来的
   名称；引擎管理器对 AI 引擎镜像也会这样做。
3. 照常安装：`bash ergon.sh install`（或 `ergon install`）。

如果没有 `ERGON_REGISTRY` 这一行，Ergon 会先尝试 `ghcr.io`；如果它无响应，就会自动改用随版本发布的镜像（前提是
该版本已同步到镜像）。如需不经 GitHub **更新**，用 `ERGON_MANIFESTO_URL=https://…/latest.json` 指向放在中国境内
地址上的版本文件副本，安装包放在旁边；安装包的 `sha256` 校验仍会进行。

## 2. 选择中国的 AI

在 **连接 › AI 账户** 中打开 **国产模型**，用你在服务商处账户的 API 密钥登录：

| 服务商 | 在哪里创建密钥 |
|---|---|
| DeepSeek | platform.deepseek.com |
| 通义千问（Qwen，DashScope） | dashscope.console.aliyun.com（同一个密钥适用于中国和国际地址） |
| Kimi（月之暗面，Moonshot） | platform.moonshot.cn |
| 智谱 GLM | open.bigmodel.cn |
| MiniMax | platform.minimaxi.com |

然后在 **默认模型** 中选择模型。密钥只能通过这张卡片输入：会在服务商处核验，并加密保存在团队的保险库中。
任何智能体都不会在对话中索要密钥。

智能体会用写信人的语言回复：界面设为中文时（设置 › 语言），团队会用中文回复。

## 3. 通过飞书、钉钉和企业微信对话

在 **连接 › 与团队对话** 中。三者都由内向外连接（长连接），**无需公网地址**，也不用在路由器上开放端口。
仅支持单聊（不支持群聊）；需要确认的事项以文本形式送达，在 Ergon 中做决定。

- **飞书或 Lark**：在开发者后台创建企业自建应用，开启机器人，粘贴 App ID 和 App Secret。选择飞书（open.feishu.cn）
  或 Lark（open.larksuite.com）。
- **钉钉**：创建企业内部应用，机器人使用 Stream 模式，粘贴 Client ID 和 Client Secret。
- **企业微信**：在管理后台的 应用管理 › 智能机器人 中，以长连接模式创建机器人，粘贴 Bot ID 和 Secret。需要公网地址的
  自建应用回调 URL 模式不使用。

保存后，在单聊中给机器人发送任意消息：它会回复一个 8 位字母数字代码，在 Ergon 中输入该代码（并输入你的密码）。
此后，你发给机器人的内容都会转给团队。

### 个人微信：实验功能

个人微信通过腾讯的 iLink API 连接，二维码会显示在 Ergon 界面上。**腾讯可能限制或封禁所使用的账号。**
因此该功能默认关闭，只有在你明确同意后才会开启，建议不要使用你的主账号。账号的访问凭据保存在团队的保险库中；
关闭即删除。

## 4. 在中国无法使用的功能

- **Ergon 云服务以及与 Ergon World 的同步**：位于中国境外，在中国不提供。
- **Anthropic、OpenAI 和 Google**：被屏蔽或不稳定。此外，在中国面向公众提供的生成式 AI 服务需要使用在中国备案的
  模型，目前没有境外模型完成备案。请使用中国的服务商。
- **本地计费**：在中国境内不进行销售和计费。

## 5. 法律提示

在中国托管或销售服务需要 ICP 许可证，将个人信息传出境外须遵守《个人信息保护法》（PIPL）。在中国向第三方提供
Ergon 之前，**请咨询当地律师**。
